    Reading these numbers

    • These are micro-benchmarks of the cell alone, run on a shared CI machine. Compare values within one run, not across runs.
    • The subjects do not offer the same guarantees. Some hand out borrows and others owned Arcs; some return old values to the writer and others drop them on a reader thread; some let a slow reader block the writer. COMPARISONS.md describes the differences.
    • The writer in the “+ writer” scenarios publishes continuously, and the readers in “Write, N readers” read continuously. Both are far harsher than a typical read-mostly workload.
    • The range drawn around each dot on the log scale is criterion's 95% confidence interval for the median.
    • baseline-leak never frees anything. It is the floor, not a contender.
